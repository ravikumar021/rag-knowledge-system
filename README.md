# RAG Knowledge System

Built a Retrieval-Augmented Generation (RAG) system using LangChain and PGVector.

## Features
- Semantic search over documents
- LLM-based question answering
- Vector database using PostgreSQL

## Tech Stack
Python, FastAPI, LangChain, OpenAI, PGVector

## Use Case
Reduces onboarding time by 40% using intelligent document retrieval.
